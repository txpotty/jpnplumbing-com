    Residential Urinal Plumbing in East Providence, RI

    Home urinals use the same rules as commercial ones. The drain is usually 2 inch, the trap is built into the china, the fixture needs a vent within code distance, and the flush valve needs either a 3/4 inch supply or a lower-flow residential valve on 1/2 inch. Your city may want a permit. We check that first.

    Home Gym and Garage Urinals in East Providence, RI

    A garage urinal saves tracking dirt into the house. We run the drain to the nearest stack or building drain, add a vent or an air admittance valve where local code allows one, and pick a compact bowl that fits the space without a full commercial carrier. Unheated garages need freeze planning. Ask us about the layout.

    Sloan Flush Valve Installation in East Providence, RI

    Sloan Royal valves are on most commercial urinals we see. We install them with the correct inside parts kit for the bowl's rated volume, set the control stop so the flush is strong without splashing, and keep rebuild kits on the truck for later service. Sensor versions mount the same way. Battery models need no wiring.

    Flushometer Urinal Installation in East Providence

    Manual flushometers are still the most common setup. Manual valves go on a 3/4 inch line with the control stop tuned and the vacuum breaker at the correct height. Handles can go left or right. ADA units need the handle within reach.

    Urinal Rough-In for New Restrooms in East Providence

    Tenant improvements need rough-in before the walls close. We space urinals 30 inches apart and 15 inches from side walls, then set carriers and run all the lines. We stay in touch with the GC daily. Rough inspection comes first.

    ADA-Compliant Urinal Installation in East Providence

    At least one urinal in a public restroom with more than one usually has to be accessible. ADA units need a rim at or below 17 inches, a 13-1/2 inch projection and 30 by 48 inches of clear floor. The flush handle has to be easy to reach. We mark it all during rough-in.

    American Standard and Kohler Urinal Installation in East Providence

    American Standard and Kohler make the china we install most. Washbrook and Bardon models come in several flush ratings, and the valve has to match the bowl. The spec sheet makes matching easy. We order both together.

    Waterless Urinal Upgrades in East Providence

    Switching to waterless is mostly a fixture swap. We remove the flush valve, cap the supply and set the waterless bowl on the same carrier. Many jurisdictions want a capped supply kept for later. That allows a future change back.
