    Copper Service Line Installation in Newport, RI

    Copper is still the choice for some homeowners. It has a long track record.     Type L vs. Type K Copper in Newport, RI

    The thickest wall belongs to Type K, the usual choice underground. Type L is lighter and mostly goes indoors. Some codes allow L for burial, but we stick with K for service lines because a thicker wall buys more years against stone contact and soil chemistry. Same fittings, different pipe.

    PEX Water Line Installation in Newport, RI

    PEX bends around corners, so a typical service run needs no fittings between the meter and the house. Coastal winds can drive cold into walls and split pipes that seem well protected, particularly during deep cold snaps. A frozen PEX line often survives where copper would crack. We still bury it below the frost depth the local code sets, and keep it covered from sunlight at the meter box, since UV light breaks it down. Short exposure only.

    PEX Service Lines for Long Runs in Newport

    We buy PEX in long coils. That makes it the easy pick when the meter sits out at the road and the house is set far back, because one coil covers the whole run without a joint. Fewer joints underground means fewer places a leak can start, and it is the joints that usually fail first.

    Damage Assessment Before Replacement in Newport
