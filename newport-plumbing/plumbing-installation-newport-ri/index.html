    Natural Gas and Propane Lines in Newport, RI

    Natural gas and propane run at different pressures, and the pipe sizing changes with them. Our licensed plumbers size each run from the appliance BTU ratings and the developed length, then choose black iron or CSST to suit the route. Code requires CSST to be bonded. Without that bond, a lightning strike nearby can arc through the tubing and start a fire.

    Gas Line Installation for New Appliances in Newport, RI

    Water heaters, ranges, dryers, fireplaces and pool heaters all pull from the same gas service. Bigger loads sometimes need a meter upgrade, and we set that up with the gas utility.

    Sump Pump Installation in Newport, RI

    A sump pump that fails during a storm usually failed months earlier: a stuck float, a seized impeller, a dead check valve or a cord unplugged for the shop vac. The pit goes to proper depth, the primary pump is sized for the inflow, and a battery backup is added on request. Where the water exits matters most. We run the discharge line far enough from the foundation that the water does not cycle straight back into the pit.

    Sewage Ejector Pump Installation in Newport, RI

    A basement bathroom sits below the sewer line, so gravity cannot carry the waste out. An ejector pump in a sealed basin lifts it up to the main drain. We size the pump and basin to the fixtures it serves, vent the basin to code, and put a check valve and a full-port shutoff on the discharge so the pump can be pulled for service. We usually install Liberty or Zoeller pumps.

    Gas Line Installation in Newport, RI

    A new range or an outdoor kitchen all start with the same math: total BTU load and the length of the run. From there we size the pipe, choose between black iron and CSST, and dig the trench for any buried section. Each joint is checked with leak solution. After that, the line sits on a pressure gauge until the inspector signs off.

    Sump Pump and Sewage Ejector Pump Installation in Newport

    Basements and crawl spaces that take on water need a sump pump, and fixtures below the sewer line need an ejector. One moves groundwater, the other moves sewage, and they are not interchangeable.
